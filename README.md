# Kedvenc kajáim

Magyar nyelvű, refluxhoz és egyéni étkezési tapasztalatokhoz igazítható AI-receptajánló PWA.

## Indítás

GitHub Pages: Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save.

Ezután: https://vevohalo-droid.github.io/kedvenc-kajaim/

Safari → Megosztás → Hozzáadás a főképernyőhöz.

## AI

A Beállítások oldalon saját OpenRouter API-kulcs és modell adható meg. A kulcs a böngésző helyi tárhelyére kerül, ezért csak saját, megbízható eszközön használd. Az AI-hívás közvetlenül a böngészőből történik, így hálózati és szolgáltatói korlátozások érinthetik. A GitHub Pages nyilvános statikus tárhely, API-kulcsot soha ne tegyél a repositoryba.

A mentett receptek helyben tárolódnak; más eszközre nem szinkronizálódnak. A receptajánlat nem orvosi tanács.
